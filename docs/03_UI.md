# PURPOSE

This document defines the user interface and user experience standards for ProfitPilot.

The objective is not simply to create an attractive interface.

The objective is to create a financial application that allows users to understand complex leveraged positions quickly, confidently, and with minimal cognitive effort.

The interface should reduce stress rather than increase it.

---

# DESIGN PHILOSOPHY

ProfitPilot follows four design principles.

Clarity

↓

Transparency

↓

Speed

↓

Confidence

Every screen should help users make better financial decisions.

The interface should never overwhelm users with unnecessary information.

---

# CORE UX PRINCIPLES

Every page should answer one primary question.

Dashboard

"Am I safe?"

Portfolio

"What do I own?"

Simulation

"What happens if...?"

Loop Builder

"How much leverage should I use?"

Exit Planner

"What should I do now?"

Settings

"How do I customize the application?"

No page should attempt to answer multiple unrelated questions.

---

# TARGET USER

Primary User

Self-custody Bitcoin investor.

Experience Level

Intermediate

Knows Bitcoin.

Knows basic DeFi.

Uses Aave.

Interested in long-term leveraged investing.

Secondary Users
